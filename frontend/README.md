# lastmilelogistics
Сервис для автоматизации логистики. В первую очередь - "последней мили".

Код пишу для себя, в развлекательных целях, кто хочет использовать - пользуйтесь, Ваши проблемы.

Как я вижу релизные фичи:
  * Можно проложить маршрут в (ЛО) Ленинградской области.
  * Можно проложить несколько маршрутов в ЛО, которые будут связаны между собой через очередь по какой-то БЛ (бизнес логике)
  * Маршрут представляет собой граф, где вершинами являются адреса
  * К адресам можно добавить БЛ
  * Существует система прав и ролей. Координатор, Исполнитель и т.п.

Техническая часть:
  * Python3, для вычислений может Rust применю
  * СУБД PostgreSQL, может еще какие добавлю
  * docker-compose

Другое:
  * Связное с картами буду брать с geofabrik (Danke!), openstreetmap (Thanks!)
  * Скорее всего буду использовать замечательный сервис openrouteservice (Danke! + Thanks!)
